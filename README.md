# Ambiente teste para implantação de sistema de atendimento com IA

Este projeto é uma página estática de demonstração para testes de implantação de um sistema de atendimento com IA, incluindo um widget de bate‑papo integrado (Zaia).

## Conteúdo
- Favicon e logo: primeira imagem fornecida (`TRAUMA/logo.png`)
- Plano de fundo: segunda imagem fornecida (`TRAUMA/trauma.png`)
- Widget de chat: carregado via Zaia com `AgentURL`

## Visualização local
1. Instale e execute um servidor estático:
   - `npx -y http-server -p 5500 -a 127.0.0.1`
2. Acesse: `http://127.0.0.1:5500/`
